# MVP ServerStatus

Desktop-приложение для мониторинга доступности серверов и сетевых устройств.

Приложение получает список серверов из Excel-файла, выполняет параллельную проверку доступности по IP-адресам и отображает текущий статус в графическом интерфейсе. При недоступности выбранных серверов система может отправлять уведомления в Telegram и по Email.

## Возможности

* мониторинг доступности серверов по IP;
* параллельная проверка нескольких серверов;
* группировка устройств по категориям;
* отображение списка доступных и недоступных устройств;
* добавление, изменение и удаление IP-адресов;
* фильтрация и сортировка таблиц;
* копирование данных из таблиц;
* Telegram-уведомления;
* Email-уведомления;
* автоматическое обновление данных;
* графический интерфейс на CustomTkinter.

### Основные модули

**`Main.py`**

Точка запуска приложения. Запускает графический интерфейс и Telegram-бота в отдельных потоках.

**`userInterface.py`**

Графический интерфейс приложения. Отвечает за отображение серверов, настройки уведомлений, добавление и редактирование IP-адресов.

**`ping_file.py`**

Модуль проверки доступности серверов. Использует параллельную обработку для одновременной проверки нескольких IP-адресов.

**`tg_bot.py`**

Telegram-бот для отправки уведомлений о недоступности серверов.

**`send_email.py`**

Отправка уведомлений по Email через SMTP.

**`excel.py`**

Работа со списком серверов и сетевых устройств, хранящимся в Excel.

## Формат списка серверов

Список устройств хранится в `ipList.xlsx`.

Файл содержит несколько категорий устройств:

* Представительства
* Склады
* Дочерние предприятия
* Центральный офис
* Корпуса

Для каждой категории указывается название устройства и его IP-адрес.

Для публичной версии проекта используются демонстрационные данные.

## Установка

Клонировать репозиторий:

```bash
git clone https://github.com/UglyXddd/ServerStatus.git
cd ServerStatus
```

Создать виртуальное окружение:

```bash
python -m venv .venv
```

Активировать его.

Windows:

```bash
.venv\Scripts\activate
```

Linux/macOS:

```bash
source .venv/bin/activate
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python Main.py
```

Приложение запускает графический интерфейс и Telegram-компонент.
